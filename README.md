# Antiscam Simulator — Frontend

Симулятор-тренажер для обучения распознаванию мошенников: пользователь ведёт диалог с мошенником в чате и по итогам получает оценку уровня безопасности своих действий.

Это клиентская часть командного учебного проекта. Бэкенд (Go + PostgreSQL + Redis) разрабатывался сокомандниками, поэтому здесь он заменен мок-режимом: без сервера приложение полностью работает на локальных данных.

## Возможности

- **Диалоговые сценарии**: игра построена на направленных графах диалогов — каждый ответ пользователя ведёт к новому узлу и меняет уровень риска сделки
- **15-минутный таймер**: на прохождение сценария даётся ограниченное время; по истечении попытка не засчитывается
- **Регистрация и история**: результаты сохраняются на сервере, доступны личные статистика и история попыток с разбором ошибок
- **Прогресс**: лучшие результаты по сценариям, бейджи безопасности, статистика по ролям (покупатель/продавец)
- **ИИ-генерация сценария**: кнопка «Сгенерировать ИИ-вариант» запрашивает у бэкенда новый вариант сценария — результат показывается, но не сохраняется в прогресс
- **Мок-режим**: при недоступности API приложение автоматически работает на локальных данных

## Технологии

- React 18 + TypeScript
- Vite
- Ant Design
- Zustand (состояние)
- React Router

## Запуск

```bash
npm ci
npm run dev
```

Приложение доступно на http://localhost:5173.

### Docker

```bash
docker build -t antiscam-frontend .
docker run -p 5173:80 antiscam-frontend
```

Образ собирается в два этапа: Node.js → сборка статики, nginx → раздача SPA с проксированием `/api/` на бэкенд.

## Структура

```text
src/
├── pages/              # Страницы: тренировка, симулятор, прогресс, результат

├── shared/
│   ├── api/            # HTTP-клиент, типы, мок-данные
│   ├── theme/          # Цвета, радиусы
│   └── ui/             # Общие UI-компоненты

```
